# 主机准入实施计划

> 英文完整计划：[host-admission](2026-10-16-host-admission.md)。沿用持续交付授权，由当前执行者内联实现，结束时进行一次新鲜完整分支评审。

目标：通过持有命名空间所有权的 Session 应用和恢复真实主机准入规则。边界：双栈 host-local/original-destination/graceful TCP/UDP；4096 目标、8192 规则、8 MiB 映像、64 MiB 日志；不新增依赖；保留现有 55 项门禁。

1. 类型化映像与确定规则：先观察完整未来/撤销成员、错误 mark/形状、容量/时间范围和目标隔离测试失败，再实现纯生成器与内核绝对时间表达式，运行全套并提交。
2. 持久 Session 与严格恢复：先观察待执行先落盘、事务/回读/持久化失败、旧/新现场恢复、新启动、无变化、范围和会话故障测试失败，再实现 v3、完整原始结构校验、代数并发检测和应用生命周期。验证未知嵌套属性拒绝；运行单元、race、vet、build 后提交。
3. 真实验收与交付：新增双栈准入、无进程未来边界、重启、原子失败、漂移和空清单撤销门禁；编译后新鲜评审，重要问题按 RED→GREEN 修复并全套验证。发布精确树，检查全部真实 CI 和产物摘要，记录版本/包观测及双语证据；验证最终头后合并并检查主分支 CI。

评审重点：可变映像/伪造 mark、各崩溃点、新启动旧证明、未知表达式与并发变更、延迟应用及未来拒绝。完整接口、文件和命令见英文计划；设计约束见配套双语设计文档。
