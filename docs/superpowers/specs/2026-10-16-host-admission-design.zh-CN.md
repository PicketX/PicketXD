# M2C4：持久主机准入

> [English (default)](2026-10-16-host-admission-design.md) | 简体中文

本批继续已授权的生产 L4 工作，实现可恢复的真实内核准入引擎，保留现有 55 项内核门禁。范围是包 API；生产命令和独立发布重载循环在引擎崩溃契约验证后接入。仅支持双栈 host-local/original-destination/graceful TCP/UDP，明确拒绝 strict；不实现 FORWARD、控制器、L7 或管理接口。

由完整 hostpolicy 清单和持久 mark 生成确定性的类型化规则映像，不直接包装私有验证后端。严格确认整个旧表后，在一个原子事务中替换自有表。使用原始 conntrack 地址、协议和端口；当前目标先拒绝 INVALID/UNTRACKED。显式拒绝优先于已标记的已建立连接；新 TCP 必须是无 ACK 的 SYN。目标独立 mark 保留 graceful 连接，退休 mark 永不复用。最后一个 Grant 消失仍默认拒绝；空目标清单只撤销保护，保留所有权标记。

使用 NFT_META_TIME_NS、字节序转换及无符号比较，在内核执行完整绝对有效区间，包括未来允许和拒绝，无需进程定时器或相对超时续期。非零时间限定为 Unix 纳秒 [1, MaxInt64]；超界在副作用前拒绝。依赖正确系统时钟和受信任的 NET_ADMIN 独占写入。

日志 v3 保存上次确认映像、待执行映像、递增尝试编号和 SHA256。保存语义目标、完整有效期和 mark，再生成精确结构。最多 4096 目标、8192 条规则、单映像 8 MiB；组合日志上限 64 MiB，容纳现有 32 MiB mark 历史和两份映像，禁止静默降级。

Session 互斥锁内依次：验证输入和映像、完整核验现场、持久发布待执行映像并保留旧确认、原子替换、接收 ACK、严格完整回读、持久确认并清除待执行。待执行发布后的任何失败均使会话故障，不返回执行凭据，必须关闭后重开。磁盘布尔值不能恢复现场确认。

同一启动恢复只接受经过日志验证的旧标记结构、确认映像或待执行映像，并根据精确现场结构裁定。未知规则、表达式、hook/policy/priority、更余链或集合/对象/flowtable、畸形或中断 dump、错误标记均无替换地拒绝。新启动保留 mark 退休记录，清除应用证明，需显式重新应用。关闭不撤销过滤。

表达式属性与生成的 wire 属性严格比较，仅忽略计数器值和内核 handle/use 元数据。校验所有嵌套属性长度与重复项，不依赖可能忽略未知表达式的解码器。完整 dump 前后读取代数并拒绝并发变化。

文件映射见英文表：hostrules 负责有界映像与表达式；hostowner/application 和 inspect 负责持久应用恢复与完整校验；owner/nft/raw/marks 接入 v3 和命名空间约束；单元测试验证时间、篡改、持久化及模糊结果；admission 内核测试验证双栈包、时间、重启、漂移、撤销及事务失败保留；report 新增必需门禁。仅内部 API 和前向日志迁移，无新依赖或配置模式。

必须通过单元、race、vet、build、集成编译与新鲜评审，再由真实 CI 验证原有 55 项及新增门禁；记录真实版本和包观测，零失败、零跳过。仅合并已评审和测试的精确树，不宣称已部署生产守护进程。
