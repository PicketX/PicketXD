# Controller Provider 设计

用户已授权自主设计、实现、验证、独立评审、推送及按预期 head 合并。
远程完整快照经本地作用域校验后映射到现有配置编译器，复用现有 owner、mark、应用与 strict 撤销流程。
静态 YAML 与 Controller 是互斥权威来源。远端命名空间 ID 只校验一致性，不作为本地内核事实。
仅接受单一 host-local/original-destination profile、明确 handling 与本地目标地址边界内的 TCP/UDP。
包括未来、过期、已撤销贡献在内的完整快照均须校验，未知字段或能力整体拒绝。
私有原子缓存同时保留原始快照及派生配置，绑定来源类型、authority、Agent、传输配置及本地范围。
拒绝版本倒退与同版不同内容；重连、重启、无效输入、断连都不延长绝对期限。
空 targets 明确撤回保护，删除最后 Grant 则保留默认拒绝保护。
只有原生应用与严格清理确认后才能报告 APPLIED；接收、下发与应用不能混淆。
TLS 正常验证证书，明文须显式选择；Token 使用有界私有普通文件。
本段不宣称管理端、七层或跨未观察间隔的持久撤权完成。
