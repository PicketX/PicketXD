# M2C1 所有权实施记录

> [English (default)](M2C1.md) | 简体中文

日期：2026-10-16。分支：`codex/m2c-host-ownership`。本增量实现仅含标记的内核所有权，不执行流量保护；真实内核验收待运行。

## 已实现

- 生产边界 `internal/hostowner`，不导入私有验证模型，不修改依赖版本。
- 在锁定 OS 线程上持有 namespace，并创建两个持久 Netlink socket，无需 setns。抽象 Unix datagram 单实例锁阻止共享网络 namespace、但挂载目录不同的进程同时认领；运行与日志 flock 额外隔离状态文件。进程退出释放描述符，不删除标记表。
- 明确 provider/Agent/runtime/boot/namespace 身份、随机安装/epoch token、完整日志校验及有界规范 JSON。pending 发布在发送前，结构读回后才能确认。新 boot 只能重新建立空所有权，不能声称恢复策略或确认执行。
- 基于描述符的 openat/mkdirat/renameat/unlinkat、不穿越符号链接的目录遍历、当前用户私有单链接常规文件、文件和父目录 fsync。即使路径重命名，后续日志操作仍绑定原目录。
- 排他创建 `inet picketx`，仅含无 hook 标记 chain/counter 规则，无 delete/flush API、hook、mark。独立有界原始读回检查 multipart 完成、中断标志、sequence/PID、完整属性/表达式结构及全部自有对象类别。
- 原 43 项内核场景仍必需；新增 7 项所有权案例，合计 50 项门禁。新案例已编译，未在这里执行。

## 本地证据

Go 1.27.0：**83 项顶层测试通过**，零失败/跳过，其中 19 项是 hostowner 测试。全量 race、vet、build 通过，所有集成包带 integration tag 编译通过。静态 prepare 二进制/重启/非法配置保留冒烟通过；CGO=0 的所有权集成 binary 经检查是无解释器的静态 ELF。二者均不能证明所有权内核行为。

初始状态机测试先对可编译桩失败，再实现。观察时间回归先失败后修复。Go overlay 将 CreateTable 故意改成 AddTable，会使 `TestOwnershipCreateIsExclusive` 失败，真实源码通过。抽象 socket 测试先发现桩允许两个 owner；本地真实 bind 被环境禁止，因此保留为必需内核案例，不声称本地通过。

## 独立评审与修复

一次独立全分支评审发现三项 Important，全部进入同一轮回归修复：

| 问题 | 失败复现与修正 |
| --- | --- |
| 固定 Netlink 解码器忽略 DUMP_INTR 并丢弃 DONE 标志 | `TestRawDumpInterruptedCompletion`，以及 `TestStrictWireObservationAndFailures` 的空 set 中断输入；独立原始 datagram 读取在丢弃完成消息前拒绝中断 data/DONE。 |
| 固定 nftables 解码器静默丢弃未知表达式 | `TestRawMarkerRejectsUnsupportedExpression` 及严格 wire 观察；原始名称/数量/属性必须仅描述一个 counter。 |
| 路径目录创建/发布可能跟随竞争插入的符号链接 | `TestDirectoryCreationSymlinkRace`、`TestJournalUsesPinnedDirectory`；持有目录描述符控制遍历、锁、读取、临时发布、rename 和同步。 |

非法完成消息及无效 UTF-8 身份测试也先发现失败再修正。修复后全量测试通过。无待补 reviewer minor，不声称做过第二轮评审。真实 native 读回和独立进程测试仍须 CI。

## 实施裁定与代价

1. 本切片先完成所有权，再提供过滤命令，落实生产简报首个前置条件，不将夹具后端直接提升为生产实现。若理解错误，可能把认领标记当成已安装保护；状态和文档明确排除此声明。
2. 发现不同 `/run` 挂载能绕过纯文件互斥后，在固定运行文件锁之外加入抽象 socket 锁。代价：禁止抽象 Unix socket 的部署不能打开所有权会话，必须报告能力错误。
3. 核实上游仍存在解码缺陷后保留固定依赖，单独实现严格原始观察。代价：少量原生接收/属性代码需要真实内核兼容验证；其测试是必需门禁，不能由 mock 代替。
