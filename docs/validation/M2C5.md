# M2C5: standalone static host enforcement

> English (default) | [简体中文](M2C5.zh-CN.md)

## Result and evidence

`picketxd enforce` connects the accepted static publication store to the M2C4 production engine. It installs host INPUT/original-destination/graceful dual-stack TCP/UDP policy, continuously validates/reloads complete publications, reports desired/applied association, and recovers with live readback. `prepare` remains nonfiltering. The runnable [example](../../examples/enforce/README.md) specifies every identity, destination and reservation flag.

The second [CI 38879876655](https://github.com/PicketX/PicketXD/actions/runs/38879876655) passed the original gates and six new process scenarios. The existing M2C4 minor remains deferred: validation conservatively rejects timestamps within the first positive Unix second. Modern dates are unaffected; this increment does not change the engine timestamp range. There are no newly deferred review items.

## Rulings and limits

- Reuse `Store.Run` rather than another publication/cache contract. Cost: its initial-invalid startup behavior remains fatal; cached invalid reload remains nonfatal during continuous operation.
- Add atomic immutable `Snapshot` and re-read after kernel IO. Cost: an additional mutex-protected read; a newer desired generation can never inherit an older receipt. A failed newer apply may leave the previous image installed, while top-level confirmation remains false.
- Verify unchanged desired state without repeating application/conntrack reservation scans. Cost: polling still performs full live structure verification. Native deadlines execute independently of polling/process lifetime.
- Derive trusted scope from the held boot/namespace identity and bind canonical Agent/profile/destinations/marks into the runtime key. Cost: scope changes require an explicit deployment/migration decision; no implicit takeover.
- Open ownership and validate the private root before opening desired state. Cost: two journals and locks; same-UID filesystem trust, stable directory identity and durability remain prerequisites. A fresh invalid publication may leave only a nonfiltering ownership marker.
- Separate desired metadata, application receipt and associated generation/hash. `--once` may print a confirmed recovered accepted policy while returning nonzero for a currently invalid publication. Cost: callers must inspect process result and desired error separately.
- Keep filters on normal shutdown and SIGKILL; explicit empty Binding inventory withdraws protection, whereas removing the last Grant retains default deny. Cost: stopping the daemon is not an uninstall operation; graceful established connections remain admitted.
- Embed the process fixture and compare it with the runnable example. Cost: a small duplicate YAML file; the standalone test binary works independently of working directory and toolchain.

Compatibility is limited to the recorded kernel/toolchain environment. Explicit mark reservation, trusted privileged writer exclusivity, correct wall clock and durable private filesystem remain requirements. The command only implements static host-local/original-destination/graceful L4. Strict teardown, Controller synchronization, service packaging, container/FORWARD, NFQUEUE/TPROXY, L7 and management remain future increments under the [delivery route](../DELIVERY.md).
