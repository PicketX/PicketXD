# M2C1 ownership implementation record

> English (default) | [简体中文](M2C1.zh-CN.md)

Date: 2026-10-16. Branch: `codex/m2c-host-ownership`. This increment implements marker-only kernel ownership, not traffic enforcement. Real kernel acceptance is pending.

## Implemented

- Private `internal/hostowner` production boundary; no private validation model imports and no dependency version changes.
- Pinned namespace and two persistent Netlink sockets created on a locked OS thread without setns. Abstract Unix datagram singleton excludes processes sharing the same network namespace even with different mount namespaces. Runtime and journal flocks add state-file exclusion; process exit releases descriptors without deleting the marker table.
- Explicit provider/Agent/runtime/boot/namespace identity, random installation/epoch tokens, complete journal validation and bounded canonical JSON. Pending publication precedes kernel dispatch; confirmation follows structural readback. New boot can establish only fresh empty ownership, never policy recovery or enforcement confirmation.
- Descriptor-relative `openat`/`mkdirat`/`renameat`/`unlinkat`, no-follow directory traversal, private current-owner single-link regular files, file and parent-directory fsync. Subsequent journal work remains bound to the opened directory even if its path is renamed.
- Exclusive creation of `inet picketx` with one unhooked marker chain and counter rule; no delete/flush API, hooks or marks. A dedicated bounded raw reader validates multipart completion, interruption flags, sequence/PID, complete attribute/expression structure and all owned object classes before confirming.
- All 43 prior required kernel cases remain mandatory; seven new ownership cases bring the gate to 50. The new cases have compiled but have not executed here.

## Local evidence

Go 1.27.0: **83 passing top-level tests**, zero failures/skips; 19 are hostowner tests. Full race, vet and build pass. All integration packages compile with the integration tag. Static prepare binary/restart/invalid-publication-retention smoke passes; the ownership integration binary built with CGO=0 is ELF static with no interpreter. Neither artifact proves ownership kernel behavior.

Initial state-machine tests failed against compiling stubs before implementation. An observation-time regression failed before correction. A deliberate `CreateTable` to `AddTable` mutation through a Go overlay causes `TestOwnershipCreateIsExclusive` to fail, while the real source passes. The abstract socket test first rejected a stub that accepted two owners; local real socket binding is prohibited, so that behavior is a required kernel case rather than a claimed local pass.

## Independent review and fixes

One fresh whole-branch review found three Important blockers. All entered one regression/fix pass:

| Finding | Failed reproduction, then correction |
| --- | --- |
| Pinned Netlink decoder ignores `DUMP_INTR` and discards DONE flags | `TestRawDumpInterruptedCompletion`, plus interrupted empty-set input in `TestStrictWireObservationAndFailures`; dedicated raw datagram reader rejects interrupted data/DONE before completion can be discarded. |
| Pinned nftables decoder silently drops unknown expressions | `TestRawMarkerRejectsUnsupportedExpression` and strict wire observation; raw names/counts/attributes must describe exactly one counter. |
| Pathname directory creation/publication can follow a raced symlink | `TestDirectoryCreationSymlinkRace` and `TestJournalUsesPinnedDirectory`; retained directory descriptors now govern traversal, locking, reading, temporary publication, rename and synchronization. |

Malformed-completion and invalid UTF-8 identity tests also reject their observed failures. The full suite passes after these fixes. There are no deferred reviewer minors; no second review is claimed. Real native readback and standalone process tests still require CI.

## Execution decisions and costs

1. Keep this slice at ownership only, before a filtering command. This follows the production brief's first prerequisite and avoids promoting the fixture backend. Cost if misunderstood: marker ownership could be mistaken for installed protection; status and documentation explicitly deny that claim.
2. Add abstract socket exclusion to the fixed runtime file lock after discovering different `/run` mounts could evade file-only exclusion. Cost: deployments that prohibit abstract Unix sockets cannot open the ownership session and must report a capability error.
3. Keep pinned dependencies and use strict raw observation after verifying the decoder deficiencies remain upstream. Cost: a small native receive/attribute implementation needs real-kernel compatibility validation; its tests are mandatory, not replaced by mocks.
