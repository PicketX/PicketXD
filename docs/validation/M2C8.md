## Rules, recovery and operational costs

Graceful image v1 encoding/hash/default/runtimeKey remain unchanged. Strict image v2 adds at most4096 sorted exact known marks from the same Agent/context ledger, including retired aliases. Unknown/out-of-context aliases refuse application/recovery/cleanup. Journal stays v4; older binaries reject v2 images. Known retired marks preserve independently allowed established traffic across physical replacement; marks are never reused.

Current deny and member/time predicates precede strict TCP established acceptance through a shared known-mark chain. A fresh TCP SYN additionally needs conntrack NEW before writing a mark. UDP uses current member checks and marking. Every reconcile confirms actual rules, performs complete both-family cleanup and rechecks coherent desired generation/hash and the earliest prior boundary. The final snapshot cannot cross validUntil and still report confirmation. Bounds include alias and guard rules:8192 rules,8MiB image/history and64MiB journal.

Native run39004655614 reproduced fresh byte q echoing on IPv6 old TCP after deletion. Typed records showed mark0 original service18443→client53155/47003. An explicit reverse UDP fixture also failed on original code in run39004816741. Strict now appends raw protected-destination/reply-direction DROP rules after all original-target dispatches, blocking reverse reconstruction while retaining original-direction outside-scope DNAT. The new layout unit regression was observed RED before the fix; native acceptance above checks the actual kernel behavior.

**Reserve strict protected local address/port pairs for services. Do not bind locally initiated clients to those source endpoints: their incoming replies can be denied.** Each protected endpoint costs one extra rule. Cleanup preserves unmarked/unrelated conntrack records; the guard still denies packets to reserved service endpoints. No global conntrack sysctl, OUTPUT policy or whole-table flush is changed.

Every configured poll and known boundary repeats full dual-family scans/readback. No cached or durable completion receipt exists. While the process is absent, kernel deadlines deny inactive traffic but no conntrack deletion occurs. Retained marked TCP may resume if permission returns before cleanup; only successfully cleaned TCP anti-resurrection is promised. UDP remains connectionless; new valid flows may resume under regrant. No TCP RST or immediate peer notification is promised. Same-boot mode/context migration requires an explicit compatible deployment. Trusted privileged-writer exclusivity, correct clock, exclusive reserved marks and durable filesystem remain prerequisites.

## Review, rulings and deferred work

One fresh whole-branch review found zero Critical, one Important and no new Minor. The Important final-snapshot boundary window was independently reproduced by TestStrictFinalSnapshotBoundaryCannotConfirm, fixed RED→GREEN and followed by the full suite. CI independently exposed the reverse-reconstruction defect and a scheduler-sensitive existing unit fixture; both were diagnosed with observed failures before correction. No re-review substituted for regression/native evidence.

Rulings, in order:

1. Use one shared known-established chain behind current members. Cost: an extra chain/alias validator, with linear bounded historical-mark rules.
2. Refuse same-boot handling migration and retain graceful/runtime identity. Cost: fresh compatible deployment; automatic migration remains future work.
3. Cleanup every strict callback with observational status. Cost: full dual-family scans each poll/boundary; no dead-process deletion.
4. Confirmation proves current packet authorization and observed cleanup, not completion across missed permission gaps. Cost: retained marked TCP may resume if permission returns before cleanup; UDP remains stateless.
5. Reviewer reserved native/CI/archive/revision/final acceptance. Require independently downloaded exact evidence. Cost: compatibility limited to the tested runner; no local privileged claim.
6. Reviewer reserved inherited issues. Keep and explicitly report them. Cost: use low-level Plan constructors and a correct clock; conservative epoch edge and capacity regression coverage gaps remain.
7. Replace the short wall-time invalid-reload unit fixture with deterministic injected time after observing live state. Cost: no real-time latency measurement in that unit; actual kernel/process deadline gates remain required.
8. Reserve protected strict endpoints and reject fallback reply traffic there. Cost: clients cannot use those local source endpoints; one extra bounded rule per endpoint. Graceful behavior and unrelated CT records remain unchanged.

Deferred Minor (four inherited items): zero-value low-level Plan bypass (real Session uses constructor); production rollback detection limited by monotonic time.Now; first-positive-Unix-second timestamp restriction; M2C7 otherwise-valid count/8MiB/Owner pre-effect capacity regression fixtures (the old zero-value fixture rejects before testing the bound). These were not silently fixed or claimed covered.
