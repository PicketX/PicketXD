## Contract

`NewScope` fixes declarative authority/epoch/Agent/namespace/context and the ordinary or NAT fixture catalog. Its fields are private; zero scopes fail. Scope identity, selected tuple catalog and handling cannot change across prepared replacements. Exact namespace handles, forwarding, listeners, Netlink namespace identity and live capability checks still need the topology guard before side effects.

`Prepare` uses shared Compile/Replace for the entire candidate, validates selected physical targets and produces no partial candidate on error. Supply only the coordinator's accepted desired predecessor; this API cannot establish whether the predecessor was applied. One scope object is retained for a fixture's lifetime; reconstructing even equivalent metadata requires a fresh fixture lifecycle. This prevents passing candidates across fixture instances.

`Materialize(at)` preserves absolute validity, same-family source/destination pairing, separate Grant/Deny domains and all matching Binding IDs. It returns independent snapshot/provenance/inventory/withdrawal collections. Inactive and revoked members remain explainable in inventory, without current rules. Protection survives the last Grant. Empty output has no wildcard/sentinel and must not be passed to nonempty M0 Apply/Revoke.

Agent removal requires explicit absence in a same-scope complete replacement plus former-target withdrawals, or a retained explicit empty predecessor. An arbitrary planner query/validation error cannot authorize removal. Withdrawals are restricted to this fixture's Agent and retain full old desired targets. They are expected ownership changes, never an installed-flow deletion list. No cumulative installed history exists in this slice.
