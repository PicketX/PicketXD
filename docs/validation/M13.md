It retains dual-stack pairing, independent absolute deadlines, active deny precedence, all Binding IDs and typed Grant/Deny provenance. Inactive desired inventory never proves installation.

- A serialized coordinator validates complete replacements, rechecks topology, confirms apply before cleanup, retains cumulative historical emitted ownership and advances confirmed policy before reporting cleanup failure. Rejected candidates do not advance state; ambiguous apply/confirmation faults the fixture and blocks cleanup. ## Real-kernel findings during integration

The first CI attempts exposed three adapter/harness assumptions: unfiltered paths need a non-filtering conntrack observation rule to activate namespace hooks before tuple proofs; caller-queued fault injection must not be assumed to join the backend's private batch; and kernel dumps normalize legacy/32-bit register aliases. Each check remains mandatory after correction.

The pinned nftables v0.3.0 decoder also discards `NFTA_CT_SREG`, losing the write-register direction for conntrack mark expressions. `TestConntrackWriteDirectionSurvivesReadbackCodec` reproduced this locally. Pin the minimal official upstream fix [0420ffbf578f](https://github.com/google/nftables/commit/0420ffbf578f058d422a8ebde0a00941da436476), pseudo-version `v0.3.1-0.20250221083444-0420ffbf578f`, rather than treating missing write semantics as confirmed. Other Netlink versions remain unchanged. Ruling: this necessary dependency change restores exact security readback; its cost is moving beyond the tagged M0 baseline, bounded by the full retained M0/bridge kernel gate.

Independent integration review found no Critical/Important runtime defect. Its two evidence gaps were addressed: empty strict withdrawal now asserts actual selected/deleted counts and old exact marked tuple absence while preserving unmanaged controls; an injected slow apply must cross future allow/deny boundaries and rematerialize before cleanup. Disabling the overdue guard with a local overlay makes that regression fail; the correct source passes.
