## 结果与证据

## 原生观察

| 新增必需场景 | 实际观察 |
| --- | --- |
| `TestOwnerKernelCleanupPreservation` | 选择/删除四个实际双栈 TCP/UDP 流，残留0；当前独立来源 Grant 保留活跃连接。未标记/其他 mark、错误物理目标及非历史来源项保留精确 ID。删除后的旧 TCP/UDP 不再 echo，保留连接仍 echo；日志字节不变。 |
| `TestOwnerKernelCleanupNATZoneID` | 真实 output DNAT 在双族将18543送至监听18443，正确选择原始元组。错误 opaque ID 与错误 zone 返回 ENOENT 且两项均保留；精确删除 zone7 保留相同元组 zone0。最终定向删除确认其余四项 NAT/UDP 全部消失。 |
| `TestOwnerKernelCleanupPreflightDrift` | 在真实扫描后注入 IPv6 不完整证据，以及实际新增 nft 规则，各自导致零删除调用。双族精确连接记录与日志字节保留，Session 清除确认。 |
| `TestOwnerKernelCleanupPartialFailure` | 实际 IPv4 删除成功，注入 IPv6 删除失败，完整原生回读报告残留1。Session 失效；重开保留当前映像，重试仅删除残留精确项。 |

新增案例均在一次性子网络 namespace 中执行，明确 opt-in 后的准备失败必须失败。双族完整扫描先于删除，错误不返回部分证据。所有权要求历史来源、原始物理目标及精确持久 mark；当前活跃权限跨旧 mark 取并集，deny 优先，绝对期限使用共享 Core 规则。

Linux [v6.17 ctnetlink_del_conntrack](https://github.com/torvalds/linux/blob/v6.17/net/netfilter/nf_conntrack_netlink.c) 在删除前校验原始元组（缺失时才用回复）、zone 及 opaque CTA_ID，不原子比较 mark/回复/策略。编码器总携带原始元组、明确 zone、观察 ID；缺失/无效 Flow 不能变成 flush 请求。方向 zone 明确拒绝，不默认为0。未知顶层元数据做结构/上限检查；其他协议不在 TCP/UDP 范围。

## 评审与裁定

一次全新独立整分支评审未发现当前 Session 路径的 Critical/Important。评审独立通过聚焦不使用缓存测试、race、integration 仅编译、diff 检查；原生/归档及整仓库声明由实际证据确认。本轮无需评审修复。

延期 Minor（本轮不改生产实现）：

- 零值 `hostrevoke.Plan` 可绕过构造并返回空成功。真实 Session 始终经 `New` 验证当前映像/台账/历史；直接使用低层 API 的调用者必须同样构造，零值加固延期。
- 当前比较能发现注入的不带单调时间的倒退值，但生产 `time.Now` 含单调读数，`Before(last)` 不识别实际壁钟回拨。成员仍按序列化壁钟期限重算，未发现错误范围删除；仍明确要求正确时钟，实际回拨检测延期。
- 既有 M2C4 epoch 后首个正秒时间戳限制也保持延期。

裁定：

- 将清理引擎与持久 strict 生命周期拆开：累计历史、strict 准入及边界调度需要独立恢复证明。代价：调用者保留旧映像，不推断完整历史，不增加自动 strict 命令/凭据。
- 内核 ID 保留四字节 opaque：内核直接比较其内部表示。代价：API 不承诺可移植整数/端序解释。
- 效果前刷新时间，检测到边界跨越或倒退则拒绝。并不与壁钟构成原子删除；实际壁钟倒退检测有上述限制。代价：失败后重开/重试，仍需未来调度集成，依赖可信特权写入与正确时钟。

历史最多32个调用者映像、累计映像 JSON 32 MiB，每映像沿用8 MiB上限。每族原生 dump 最多64 MiB，完整快照最多262144个类型化流。重复/损坏/不完整证据先于删除失败。当前 mark 必须活跃，历史物理身份必须匹配含退休实例的持久 mark 台账，无法用无效历史重定位已知 mark。

执行清理时发生错误使 Session 失效、清除现场确认并要求重开，过滤和持久日志保留。成功仅返回限定范围计数：Selected、ACK 确认 Deleted、ENOENT 单列 Absent、回读 Remaining。确认不完整时 Remaining=-1；残留、部分删除及确认漂移均失败。不持久证明 strict 完成。

## 剩余范围

调用者历史是已校验候选所有权证据，不是全部映像曾实际发射或历史完整性的证明。Session 始终加入其真实当前映像；历史 Grant 到期不抹除 graceful 已建立连接所有权。仅历史来源/物理目标/mark 均匹配者可被选择。

现有 graceful 映像仍可能保留已建立流量；本原语不承诺进程失联 strict 调度，也不单独保证所有连接无法重新形成跟踪。后续接入持久累计所有权历史、strict 准入及协调/边界恢复，再按[路线](../DELIVERY.zh-CN.md) 推进 Controller、容器/FORWARD、L7 和管理端。兼容范围仅限已记录真实环境。
