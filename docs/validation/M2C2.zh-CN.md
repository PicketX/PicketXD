## 实现与本地证据

`internal/hostpolicy` 消费共享不可变计划和可信 authority/context 范围，先校验完整选中库存，再投影活跃成员。支持任意规范 IPv4/IPv6 TCP/UDP 目标，保留 Resource/贡献 UID、Binding 来源和独立绝对期限。完整库存保留未来/过期/撤销成员；最后 Grant 到期仍保留保护，最后 Binding 移除可产生空期望输出。拒绝空值、未知 Agent、authority/context/namespace 不匹配及不支持的选中休眠目标。返回的嵌套数据可独立修改，并发求值不共享可变结果。

新增六组测试均先对可编译桩失败，再随实现通过。覆盖真实 configuration.Decode/Compile/Replace、来源范围、同 ID 的 Grant/Deny 独立域、未来 deny、NotBefore/排他结束、永久成员、UID 重建、撤回、可信范围拒绝和修改/并发检查。Go 1.27.0：**89 项顶层测试通过**，零失败/跳过；全量 race/vet/build、静态准备/重启/非法发布保留冒烟通过，集成包编译通过。

现有 host 夹具仅在集成测试中将 hostpolicy 输出转换为私有内核输入。新增必需 `TestHostPolicyCompilerPorts`，实测双栈 TCP/8001 与 UDP/8002 的允许来源、无关来源拒绝及无关服务控制。原 50 项必需场景全部保留，现共 51 项。真实运行和准确 head 证据将在 CI 后记录，不从编译结果推断。

## 独立评审

一次独立全分支评审未发现 Critical、Important 或 Minor 问题，逐项核对计划的五个重点，并独立通过编译器/报告的无缓存 race 测试和 diff 检查。真实报文行为明确留待 CI；已有 hostowner 内部实现和生产执行就绪不属于本批范围。无待补问题。

## 实施裁定

- 保留共享 Core 的上下文契约：通过端点地址缩小物理匹配，Binding 声明不能与完整已解析上下文矛盾。初始缩小测试已在实现前修正。若理解错误，可能拒绝合法窄端点或接受变宽的运行事实。
- 未来 deny 保留在期望库存和边界求值中，不宣称已具备进程消失后的可靠安装。若误当内核凭据，Agent 停止后可能遗漏限制；生产 apply 边界仍未开放。

## 剩余生产边界

本编译器不分配 conntrack mark、不执行 Netlink、不发布已应用日志、不返回确认凭据。仅标记所有权和 prepare 保持不变。生产引擎仍须定义版本化结构契约、保留 mark 分配/退休、持久已应用历史和进程消失后可靠的限制边界，再暴露主机执行命令。七层和管理端仍属后续工作。
