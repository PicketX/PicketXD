## Reproduce

Run unprivileged checks first:

```sh
go mod download
go test ./...
go test -race ./...
go vet ./...
go build ./...
```

On a disposable capable Linux host, with `unshare`, network namespaces, nftables/conntrack kernel support and root or passwordless sudo:

```sh
PICKETX_KERNEL_TESTS=1 scripts/test-kernel.sh
```

The script builds with `CGO_ENABLED=0` before privilege use, runs prebuilt tests in isolated parent namespaces, and preserves failures. `ip` is used only for test-network failure diagnostics. Runtime adapters use Go Netlink calls, not nft/conntrack commands or C libraries. No host firewall table or conntrack flush is used. Every scenario creates its own enforcement/client/server namespace and tests both unfiltered paths before applying policy.

Artifacts in `artifacts/`: `nft.json`, `ct.json`, `kernel.txt`, `go.txt`, `modules.txt`, `report.json`. CI archives evidence even on failure. The report retains failed/skipped/unsupported distinctions and revocation counts; `Remaining=-1` means unconfirmed/not applicable, never successful zero cleanup. Every required scenario must have an observed pass; missing/skipped cases fail the job.

## Findings and limits

- Concatenated interval sets with native element timeouts work on the measured kernel using the pinned nftables library. A set per private fixture contribution keeps overlaps and independent deadlines separate; this is validation code, not an optimized production policy compiler.
- Remaining lifetime is derived from the absolute expiry, rounded down to kernel milliseconds. Expired/submillisecond memberships are omitted rather than accidentally created without a timeout.
- Strict and NAT scenarios observed `Selected=2, Deleted=2, Remaining=0` for the withdrawn IPv4/IPv6 flows. Remaining valid grants, unrelated unmarked traffic and the independent NAT mapping continued exchanging real packets.
- Conntrack deletion is scoped by ownership, original/reply tuples, family and zone. vishvananda/netlink dumps a family and deletes selected entries; the operation is not an atomic arbitrary kernel predicate. Interrupted dumps and partial deletion are errors, followed by confirmation where possible. No event stream was implemented or selected here.
- nftables accepts only a fresh TCP SYN for new authorization. Established marked traffic provides graceful expiry; strict withdrawal applies the candidate first and then removes withdrawn state. Deletion is not a TCP reset/application socket-close guarantee.
- Initial IPv6 failures came from disposable fixture startup: new-link forwarding and neighbor convergence. Fixtures set forwarding before link creation, install permanent test neighbors, and prove both unfiltered paths. Denial alone cannot pass on a broken test network.
- Fault injection validates atomic nftables rejection and conntrack partial-error reporting; large policy/conntrack tables, concurrent grant changes, broad kernel matrices and production lifecycle/recovery remain unmeasured.
- Fixture DTOs represent expected effective snapshots, not the production Grant compiler. M1 must add shared Core union/defaulting/domain conformance before the Gitea workflow. Controller transport, authentication, events, activity renewal and UI are outside M0.

## Final review follow-up

The independent review identified two evidence gaps, addressed in the fix pass: integration helpers now log actual revocation counts before failure assertions, and the event reader retains historical strict/NAT failure records; restart now reapplies an active snapshot near expiry and observes both families against the original deadline. A deliberate full-TTL mutation in run [38547705369](https://github.com/PicketX/PicketXD/actions/runs/38547705369) made `TestRestartPreservesDeadline` fail as intended (and also failed independent deadlines). The correct backend was restored before final acceptance.

Deferred minor: accepted echo server connections are not explicitly collected at topology teardown. The isolated test process releases them on exit; repeated tests in one process need synchronized socket/goroutine cleanup. This is not a production Agent lifecycle implementation.
