## Review and regression fixes

A fresh independent whole-branch review found two Important issues, no Critical issues, and one Minor item:

- Retained-contribution retargeting initially bypassed shared replacement checks. `hostpolicy.CompileInput` now retains immutable full input; images are recompiled and compared to that source. A separate durable baseline retains revoked/dormant contributions, unbound entries and trusted contexts through withdrawal/reboot. `networkplan.Replace` validates the next direct transition before any mark publication. Active, revoked, unbound and new-boot retarget regressions were observed RED then GREEN, with fresh-ID reissuance accepted.
- Configured marker-only prior state initially bypassed generation bracketing. Native inspection now brackets marker-only and full images, including absence, and rejects concurrent changes. The regression executes `nftKernel.Observe`, not just the image helper, and was observed RED then GREEN.
- Initial pending-publication failure now reports phase `unknown` even before an in-memory application record exists; the regression was observed RED then GREEN.

The first native run [38867017243](https://github.com/PicketX/PicketXD/actions/runs/38867017243) correctly failed: Linux explicitly dumps the bitwise BOOL operation, while the pinned encoder omits that default. A regression reproduced the mismatch before the fix; semantic normalization now accepts only explicit `NFTA_BITWISE_OP=0`, still rejecting other operations, malformed/duplicate envelopes and unknown attributes. The complete corrected native run passes.

Deferred minor: the intended timestamp range starts at Unix nanosecond 1, but validation conservatively rejects timestamps during the first positive Unix second. Modern policy dates are unaffected; no compatibility claim covers that exceptional epoch range.

## Rulings and remaining boundaries

- Each image, including empty withdrawal, has one extra unhooked owner-chain counter rule with its digest. Cost: one rule; benefit: semantically distinct images cannot be confused when their packet expressions coincide.
- The pinned library cannot unmarshal byteorder ECHO replies. The writer therefore uses its Go expression encoder and the already held strict namespace Netlink socket for atomic UAPI messages without ECHO, validates ACKs, and independently reads the complete live structure. Cost: maintaining a small UAPI serializer; no dependency upgrade or command-line nft/conntrack runtime.
- NFT dumps are bounded to 32 MiB, each full image/input/baseline to 8 MiB, and the combined journal to 64 MiB. Cost: bounded memory/IO; OS socket limits can reject large transactions safely with previous rules retained.
- Replacement is checked from the last confirmed full input. Cost: a publisher sequence whose intermediate versions were never applied may need explicit fresh-ID reissuance. Boot recovery clears application proof while retaining baseline and mark retirement.
- Native behavior, normalization and ACK ordering are judged by the recorded actual packet/recovery gates. Cost: UAPI maintenance and compatibility limited to the recorded environment. The kernel wall clock, privileged-writer exclusivity, explicit mark reservation and filesystem durability remain prerequisites; marker/digest values are collision detection, not authentication against NET_ADMIN.
